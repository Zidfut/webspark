# Starter Layout (Vite)

Коротко: невеликий стартовий шаблон для верстки на основі Vite + SCSS.

Команди:

```bash
npm install
npm run dev
npm run build
npm run preview
```

Деталі:
- SCSS імпортується у `src/main.js` і обробляється Vite.
- PostCSS + Autoprefixer підключені через `postcss.config.cjs`.

Файли: [starter/index.html](starter/index.html), [starter/src/main.js](starter/src/main.js), [starter/src/style.scss](starter/src/style.scss)
